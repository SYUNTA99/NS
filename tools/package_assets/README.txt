============================================================
 NS  -  3D アクションプラットフォーマー（就職作品）
============================================================

■ この作品の核
失敗を「理不尽」ではなく「自分の操作のせい」だと感じられる
3D アクションを目指して作っています。
入力・判定・視界・奥行き・学習の5つの理不尽を一つずつ潰し、
操作の手触り（慣性・加速・重力の質感）を物理チューニングで
作り込むことに集中した作品です。

■ 動作環境
- Windows 10 / 11（64bit）
- 必要なランタイムDLLを同梱しているため、別途インストールは不要です

■ 起動方法
「実行環境」フォルダを開き、Game.exe をダブルクリックしてください。
※ Game.exe は同じ「実行環境」フォルダ内の Assets / Shaders / *.dll を参照します。
   移動するときは「実行環境」フォルダごと移動してください。

■ 操作方法
  移動 ........ W A S D ／ 左スティック
  ジャンプ .... Space ／ A ボタン（長押しで跳躍の高さが変わります）
  カメラ ...... マウス ／ 右スティック
  終了 ........ Esc

■ フォルダ構成
  実行環境/ .................. 実行一式（この中の Game.exe を起動）
    Game.exe ................... 実行ファイル
    Assets/ .................. モデル・テクスチャ等のアセット
    Shaders/ ................. シェーダ（実行時にコンパイルされます）
    *.dll .................... 実行に必要なランタイム
  ソースコード/ .............. 自作分のみ（外部ライブラリは除く）
    THIRD_PARTY_NOTICES.txt .. 使用した外部ライブラリとライセンス
    Licenses/ ................ 各ライブラリのライセンス全文
  README.txt ................. このファイル
